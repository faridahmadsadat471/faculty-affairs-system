# Faculty Affairs System

A Faculty Affairs Management System designed for university administration.

## About
This project aims to provide a digital system for managing university faculty affairs.

## Technologies
- Node.js
- Express.js
- MongoDB
- JavaScript
- React
- Tailwind CSS

## Project Structure
```text
faculty-affairs-mern/
├── backend/
└── frontend/
```

## Run locally

Install dependencies with `npm ci` in each folder. Start the backend with `npm run dev` from `backend/`, then start the frontend with `npm run dev` from `frontend/`. Open http://localhost:5173. Configure the backend using `backend/.env.example`; keep the real `.env` files private. The frontend uses `/api` through its development proxy to port 5000 by default.

See [the frontend guide](frontend/README.md) and [the backend guide](backend/docs/backend-guide.ps.md) for setup, features, permissions, and tests. Local Postman assets, test-support helpers, deliverables, agent instructions, installed dependencies, and generated builds are excluded from this repository. Some backend integration tests need the excluded local test-support helpers.
